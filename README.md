# BiDen Dental Clinic Website

BiDen adalah website untuk klinik gigi yang menyediakan berbagai layanan kesehatan gigi untuk pasien. Website ini bertujuan untuk mempermudah pasien dalam mencari informasi tentang layanan yang tersedia, membuat janji temu dengan dokter gigi, dan mengakses berbagai artikel kesehatan gigi.

## Fitur

Website BiDen memiliki beberapa fitur utama sebagai berikut:
- **Beranda**: Menampilkan informasi umum mengenai klinik, layanan, dan testimonial dari pasien.
- **Tentang Kami**: Menampilkan daftar dokter gigi beserta gelar spesialisasi mereka.
- **Service/Layanan**: Menampilkan berbagai layanan yang disediakan oleh klinik, seperti pencabutan gigi, pemasangan behel, dan perawatan gigi.
- **Produk**: Menampilkan berbagai produk yang kami sediakan beserta kegunaan dan harganya.
- **Kontak**: Menyediakan informasi tentang alamat klinik, nomor telepon, dan email untuk pertanyaan lebih lanjut.
- **Artikel**: Menyediakan berbagai artikel kesehatan gigi untuk memberikan edukasi kepada pasien.
- **Buat Janji Temu**: Fitur untuk memudahkan pasien membuat janji temu dengan dokter gigi.

## Teknologi yang Digunakan
- **HTML** untuk struktur dasar halaman.
- **CSS** untuk styling dan desain responsif.
- **JavaScript** untuk interaktivitas pada halaman.
- **PHP** untuk pengelolaan formulir dan backend.
